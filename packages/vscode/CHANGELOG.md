# Changelog

All notable changes to the "vscode-theme-zellner" extension will be documented in this file.

## [0.1.0] - 2026-09-26

### Initial Release
- Initial port of Ron Aaron's classic Zellner Vim light colorscheme to VS Code.
- Modern 2026 Light architecture with 340 workbench color tokens.
- Full TextMate scope coverage across 113 token rules.
- Native semantic highlighting support for modern language servers.
- Faithful reproduction of classic Zellner visual selection, comment, keyword, and string styling.
- **Zellner Dark**: dark counterpart pairing classic Zellner syntax hues with modern 2026 Dark workbench architecture (326 color tokens, 118 TextMate rules).
