# Changelog

All notable changes to the "vscode-theme-zellner-extended" extension will be documented in this file.

## [0.2.0] - 2026-09-29

### Changed
- Removed redundant **Zellner Bright Blue** and **Zellner Bright Blue Dark** themes (which shared the same primary blue accent as **Zellner Bright** / **Zellner Bright Dark**), streamlining the extended pack to 8 distinct themes.

## [0.1.1] - 2026-09-28

### Changed
- Improved Quick Open / Command Palette selected-row and match contrast across VS Code versions.

## [0.1.0] - 2026-09-26

### Initial Release
Extended companion pack adding light and dark variations to the core Zellner themes:
- **Zellner Bright** & **Zellner Bright Dark**: high-contrast counterparts with vibrant tab and workbench accents.
- **Zellner Bright Magenta** & **Zellner Bright Magenta Dark**: vibrant magenta accent spins.
- **Zellner Soft** & **Zellner Soft Dark**: lower-contrast, desaturated, eye-comfort spins.
- **Zellner Pastel** & **Zellner Pastel Dark**: pastel-toned, low-saturation variations.
