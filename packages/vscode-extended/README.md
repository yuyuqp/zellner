# Zellner Theme Extended for Visual Studio Code

The extended companion pack adds ten light and dark variations to the two core themes in [Zellner Theme](../vscode/README.md):

* Zellner Bright and Zellner Bright Dark
* Zellner Bright Blue and Zellner Bright Blue Dark
* Zellner Bright Magenta and Zellner Bright Magenta Dark
* Zellner Soft and Zellner Soft Dark
* Zellner Pastel and Zellner Pastel Dark

Install this extension alongside the core pack to use these additional variants. Select one through **Preferences: Color Theme** in the Command Palette.

## Building

From the monorepo root, run `pnpm build` to generate both packs, or `pnpm run build` here to generate these ten themes only.
